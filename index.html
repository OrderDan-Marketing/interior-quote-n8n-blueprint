室內設計報價自動化

以 n8n 把「翻型錄、比價、分配利潤率、排版」交給系統,設計師只做確認。

  • LINE 通知

v0.1 草案 · 2026-10-11 · 待貴公司確認

現況

  1. 人工翻各廠商型錄查價
  2. 人工算利潤率
  3. 人工排版輸入
  4. 一份報價單約 3–5 個工作天

導入後

  1. 型錄集中在試算表
  2. 圖面 AI 辨識材料清單
  3. 系統比價、分流通知
  4. 設計師逐項確認
  5. 自動產出報價單

現況與目標

現況

  • 報價單涵蓋多個工種,每個工種都要翻不同廠商型錄查原始價格。
  • 查到價格後,再依工種人工計算與分配利潤率。
  • 格式整理與逐項輸入全靠人工,一份報價單約需 3–5 個工作天。

目標

  • 廠商型錄電子化,集中在一份試算表「資訊查詢」,每個工種一個分頁。
  • 設計定稿後,圖面直接由 AI 辨識出材料清單(廠商、品項、數量、單位、計價方式)。
  • 系統自動到「資訊查詢」比價:有價格的直接寫入預估價;沒有的分流通知設計師詢價。
  • 設計師只做逐項確認,確認完成即生成數位化報價單。

範圍邊界

  • 系統不取代設計師的最終判價;每筆價格都經設計師確認。
  • 系統不自動把報價單送給客戶;送出由人決定。
  • 型錄裡沒有的品項仍由人詢價,系統只負責提醒、收回結果並歸檔。

四條工作流

A型錄入庫(建立與更新電子型錄)

觸發
廠商型錄檔放入 Drive「型錄收件」資料夾。
步驟
  1. n8n 偵測新檔
  2. 解析(Excel 直接讀;PDF / 掃描圖用 AI 辨識擷取品項與價格)
  3. 轉成統一欄位
  4. 寫入「資訊查詢」對應工種分頁
  5. LINE 通知負責人核對
說明
第一輪向廠商取得電子型錄後掃描一輪建立基礎資料;之後廠商更新型錄時重跑同一流程。

B圖面辨識(設計定稿 → 材料清單)

觸發
設計師把定稿圖面上傳到該案 Drive 專案資料夾。
步驟
  1. n8n 逐張取圖
  2. 送視覺模型
  3. 輸出每張圖面的材料項目:工種、廠商、品項 / 型號、數量、單位、計價方式、所在圖面
  4. 彙整所有圖面
  5. 寫入該案「專案報價」的「辨識清單」分頁
  6. 狀態「待比價」
說明
計價方式依統一規則標準化(例如坪、才、尺、米、式、組;規則由貴公司定義);AI 輸出不符規則者標記「待確認單位」。

C比價分流(核心)

觸發
辨識清單寫入完成。
步驟
  1. 依工種分流
  2. 到「資訊查詢」對應分頁比對(第一順位:廠商 + 型號完全一致;第二順位:廠商 + 品項名稱相符)
  • 命中:寫入原始價格 → 套該工種利潤率 → 算出預估報價 → 狀態「已匹配,待確認」。
  • 未命中:狀態「待詢價」→ LINE 推播給該案設計師(品項、所在圖面、缺哪個資訊)→ 設計師詢價後在工作簿回填 → n8n 把新品項寫回「資訊查詢」歸檔 → 該筆回到比價。
結果
整案所有品項一次比對完成,設計師收到一則 LINE 總覽:已匹配幾項、待詢價幾項、工作簿連結。

D確認與報價單生成

觸發
設計師在「比價結果」分頁逐項確認(可調整價格或數量),全案狀態皆為「已確認」。
步驟
  1. n8n 讀取已確認清單
  2. 依工種分組套用報價單模板(Google Sheets / Docs)
  3. 匯出 PDF 存入該案 Drive 資料夾
  4. LINE 通知設計師連結
說明
報價單模板沿用貴公司現行格式,欄位對應在導入階段確認。

分流與計價規則

  • 匹配鍵順序:工種 → 廠商 → 型號(精準)→ 品項名稱(次要)。
  • 同廠商同品項有多個規格價格:視為未命中,交設計師選擇。
  • 利潤率:依工種讀「設定」分頁;個案要調整由設計師在確認階段改。
  • 單位換算:只在規則表有定義的單位之間換算;沒有定義的標記待確認,不自行推算。
  • 狀態值固定四種:
待比價 已匹配,待確認 待詢價 已確認

導入階段

時程在需求範圍確認後排定。

  1. 階段 0 盤點
    工種清單、各廠商型錄取得方式與格式、計價單位規則、各工種利潤率、現行報價單模板、設計師名單
  2. 階段 1 環境建置
    Zeabur 兩套 n8n、Cloudflare 存取保護、Google API 與 Drive 資料夾、LINE 官方帳號
  3. 階段 2 型錄電子化
    建立「資訊查詢」工作簿與工種分頁,完成首輪建檔(工作流 A)
  4. 階段 3 圖面辨識試跑
    以已完成的歷史設計案跑工作流 B,核對辨識結果與人工清單的差異
  5. 階段 4 比價分流與 LINE 通知
    工作流 C 上線,用歷史案驗證匹配結果
  6. 階段 5 確認流程與報價單生成
    工作流 D,對照歷史報價單核對格式
  7. 階段 6 上線與交接
    設計師操作說明、沙箱 → 主環境搬遷演練

待貴公司確認事項

  • 工種分頁完整清單(目前列出:窗簾、地板、拆除、水電、弱電)
  • 各廠商型錄現有格式(PDF / Excel / 紙本)與取得方式
  • 計價單位統一規則與換算(坪、才、尺、米、式、組 等)
  • 各工種利潤率的設定方式(固定比例,或依案調整)
  • 設計圖面的格式(CAD 匯出 PDF、圖檔),圖面上是否已有材料表或建材標註;辨識準確度取決於此
  • 現行報價單模板(格式、欄位、簽核欄)
  • 設計師名單與 LINE 通知方式(個人推播或群組)
  • 要託管到 Cloudflare 的網域
  • AI 視覺模型供應商與費用承擔方式
